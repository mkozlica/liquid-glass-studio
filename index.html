A browser experiment in liquid optics.

One canvas. Your own glass.

Download the source for the reusable renderer and this studio. No framework or dependencies required. Serve the files over HTTP, then import the module:

import { LiquidGlass } from './liquid-glass.js';
const glass = new LiquidGlass(document.querySelector('canvas'));
glass.setOptions({ refraction: 0.65, dispersion: 0.3, frost: 0.06 });
glass.setText('HELLO');

The renderer bends its own scene or an uploaded image. To refract a webpage, supply a rendered image or canvas of that page.
